# Proteus Simulation

This folder contains the Proteus simulation used to demonstrate the
main SRSHMS control and warning logic.

Since exact simulation models may not be available for the selected
radar and microphone modules, controllable inputs are used to
represent their outputs.

The simulation focuses on validating:

1. Sensor input handling
2. Sensor-fusion decision logic
3. Left/right warning
4. BJT-based vibration motor driving
5. Crash detection logic
6. Emergency countdown
7. Cancel operation
8. Local alert behavior
